{# The self-contained HTML export: one file that plays and reads on its own. This is the Share artifact - what somebody without the app gets. Rendered by scribe.exports.html_bundle.write, not by scribe.web: the exporter has its own Jinja environment (autoescape on, the clock and band filters), so the CLI never imports the web layer. Everything the page needs is inside it: the styling below, the transcript markup from _transcript_macros.html (the same macro the app's panel uses, so the attributes are the same), the audio as a data: URL or a sidecar file next to this one, and a small inline script for click-to-seek and follow-along highlighting. No htmx, no fetch, no localStorage, nothing on the network.
