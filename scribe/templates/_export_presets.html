{# The preset select of the export dialog, on its own so POST /settings/presets can send it back with the new preset chosen when the save came from the dialog (HX-Target names it). Context: presets [{name, label, options_json, builtin}], selected (a name or none), preset_select_id. Each option carries its options as JSON in data-options; app.js fills the form's fields from it on change, and the blank "Custom" entry is what the select falls back to once a field is edited by hand. The JSON is escaped like any attribute; the browser decodes it before app.js parses it. #}
