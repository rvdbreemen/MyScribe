{{ cpu_fallback.label }}

On a machine with an NVIDIA card, a job whose GPU cannot be reached - a driver that stopped working, a card the system no longer sees - is refused with a sentence rather than run on the CPU, which is about thirty times slower. Turn this on to have such a job run on the CPU anyway; every transcript records which one it ran on. A machine without an NVIDIA card always uses the CPU and is not affected.
