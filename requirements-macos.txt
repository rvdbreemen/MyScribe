# engine (CTranslate2) has no Metal backend, so without this transcription is
# int8 on the CPU; with it, `scribe.accel` picks the `mlx` backend and the run
# row says so. Diarization (pyannote) needs nothing extra: PyPI's torch for
# macOS carries the MPS backend.
